# JSON verstehen – eine interaktive Reise

Eine interaktive Lernseite, die das **JSON-Format** für Einsteiger:innen erklärt
(Deutsch, ca. 16–17 Jahre) – gemacht für den Beamer und für Laptops und Handys der Schüler:innen.

**🔗 Live:** https://ddaehling.github.io/json-verstehen/

## Die Kapitel
| # | Kapitel | Was passiert |
|---|---|---|
| 00 | Start | Der Schriftzug „JSON“ setzt sich aus echten JSON-Zeichen zusammen |
| 01 | Die Idee | Animierte Anfrage: App fragt den Server, JSON kommt zurück |
| 02 | Vom Zettel zum JSON | Eine handgeschriebene Notiz verwandelt sich in JSON |
| 03 | Anatomie | Jedes Zeichen erklärt – mit automatischer Tour |
| 04 | Werttypen | Die sechs Typen + Mini-Spiel **Typ-Detektiv** (mit Fallen wie `"42"`) |
| 05 | Bauen & Verschachteln | Schritt für Schritt – Code und „Kisten in Kisten“ nebeneinander |
| 06 | JSON in echt | Wetter-, Chat-, Spiel- und Musik-App bauen sich live aus dem JSON |
| 07 | Spielwiese | Eigener Editor mit Baumansicht und 7 **Missionen** |
| 08 | Fehler-Jagd | 12 kaputte Pakete in 3 Leveln, Sterne statt Punkte |
| 09 | Quiz | 10 Fragen mit Auswertung „Das kannst du noch üben“ |
| 10 | Spickzettel | Eine Seite zum Ausdrucken (A4) oder als PDF |

## Gut zu wissen
- **Eine einzige Datei** (`index.html`, ca. 450 KB). Läuft ohne Internet: Datei speichern und im Browser öffnen –
  sie lässt sich auch einfach in Moodle, Teams oder IServ hochladen.
- Fehlermeldungen erklären auf Deutsch, **was** falsch ist und **wo** (inkl. typisch deutscher Fehler wie `1,68` statt `1.68`).
- Hell/Dunkel umschaltbar, per Tastatur bedienbar, respektiert „Bewegung reduzieren“.
- Alle Personen, Chats und Messwerte in den Beispielen sind ausgedacht.

## Selbst anpassen
Alle Inhalte – Quizfragen, Fehler-Aufgaben, Missionen, Beispiele – stehen gebündelt im Skript
`<script id="data">` unten in der `index.html` (markiert mit ✏️). Dort lassen sie sich ohne
Programmierkenntnisse ändern oder ergänzen.
