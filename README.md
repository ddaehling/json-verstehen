# JSON verstehen – interaktive Lern-App

Eine interaktive Web-App, die das **JSON-Format** für Einsteiger:innen erklärt
(Deutsch, ca. 16–17 Jahre).

**🔗 Live:** https://ddaehling.github.io/json-verstehen/

## Was drin ist
- Läuft komplett im Browser – keine Installation, kein Internet nötig (eine einzige Datei: `index.html`)
- Live-Editor mit Syntax-Hervorhebung, aufklappbarem Baum und **deutschen Fehlermeldungen**
- Interaktive Anatomie-Ansicht, die 6 Werttypen, ein Schritt-für-Schritt-Builder
- „Zettel → JSON“-Vergleich, Fehler-Jagd-Spiel und ein Quiz
- Hell/Dunkel-Umschalter, tastaturbedienbar, für Beamer und Smartphone geeignet

## Eigene Anpassung
Quiz-Fragen, Fehler-Aufgaben und Beispiele stehen als einfache Arrays unten im
`<script>`-Block der `index.html` und lassen sich leicht für den eigenen Unterricht ändern.
