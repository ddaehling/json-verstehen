Die Grundidee

JSON ist ein ordentlicher Steckbrief

Jedes Mal, wenn du eine Wetter-App öffnest, ein Spiel lädst oder durch deinen Feed scrollst, holt sich dein Handy im Hintergrund Daten von einem Server. Diese Daten müssen so verpackt sein, dass Computer sie eindeutig verstehen – und Menschen sie trotzdem lesen können. Genau dafür gibt es JSON (JavaScript Object Notation).

Stell dir einen Steckbrief aus einem Freundebuch vor: Links steht das Feld (Name, Alter, Hobbys), rechts dein Eintrag. JSON funktioniert genauso – nur in einer festen Schreibweise, die jeder Computer der Welt eindeutig lesen kann.

Austausch

JSON ist die gemeinsame Sprache, in der sich Apps und Server Daten zuschicken – pausenlos, millionenfach pro Sekunde.

Lesbar

JSON ist reiner Text. Du kannst es lesen – und der Computer auch. Das ist der ganze Trick dahinter.

Neutral

Python, JavaScript, Java … fast jede Programmiersprache versteht JSON. Es gehört keiner Sprache allein.
