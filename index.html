01

Die Idee

Apps reden ständig miteinander.

Wenn du die Wetter-App öffnest, ein Level lädst oder durch deinen Feed scrollst, fragt dein Handy im Hintergrund bei einem Server nach Daten. Die Antwort kommt sehr oft im selben Format zurück: JSON. Probier es aus!

Tippe auf
„Wetter abrufen“

Server
wetter-api
  1. Anfrage: Die App fragt den Server: „Wie ist das Wetter in Köln?“
  2. Antwort: Der Server schickt die Daten als JSON zurück.
  3. Anzeige: Die App liest das JSON und baut daraus den Bildschirm.
antwort.json
// Hier erscheint gleich die Antwort des Servers
📦

Das Paketformat

In JSON verpacken Apps und Server ihre Daten, bevor sie sie verschicken.

👀

Für Mensch und Maschine

JSON ist reiner Text: Du kannst ihn lesen – und jedes Programm auch.

🌍

Versteht fast jede Sprache

Python, JavaScript, Java, Swift, C# … fast jede Programmiersprache kann JSON lesen und schreiben.

🗣️

Wie spricht man das?

JSON steht für JavaScript Object Notation und wird meist wie der Name „Jason“ ausgesprochen.

02

Ordnung ins Chaos

Aus einem Zettel wird ein Steckbrief.

Erinnerst du dich an Freundebücher? Links steht das Feld (Name, Alter, Hobbys), rechts dein Eintrag. JSON funktioniert genauso – nur mit einer festen Schreibweise, die jedes Programm versteht. Drück auf Verwandeln und schau zu.

→
Feld im Steckbrief→Schlüssel "name"
Dein Eintrag→Wert "Mia"
Ganzer Steckbrief→Objekt { … }

Links versteht es nur ein Mensch. Rechts versteht es jedes Programm – weil die Struktur fest ist.

      10
      
      
      
        
      Zum Mitnehmen
      
        
      Dein Spickzettel.
      
        
      Alles Wichtige auf einer Seite – zum Ausdrucken, als PDF oder als Foto fürs Handy.
      
      
      
    
      
    
      Tipp: Beim Drucken wird nur der Spickzettel ausgegeben.
      
    
      
      
      
        
      Spickzettel
      JSON auf einen Blick
      
        { }
      
      
      
      
        
      1 So ist ein Objekt aufgebaut
      
        
      
        
        
          
      • { } umschließen ein Objekt, [ ] eine Liste.
        • 
          
      • "name" ist ein Schlüssel – immer in doppelten Anführungszeichen.
        • 
          
      • : trennt Schlüssel und Wert, , trennt die Einträge.
        • 
        
      
      
      
      
      
        
      2 Die sechs Werttypen
      
        
        
          
      • Text (String)"Hallo"
        • 
          
      • Zahl (Number)16   -3   1.68
        • 
          
      • Wahrheitswert (Boolean)true   false
        • 
          
      • null (kein Wert)null
        • 
          
      • Objekt{ "a": 1 }
        • 
          
      • Liste (Array)[1, 2, 3]
        • 
        
      
      
      
      
      
        
      3 Die goldenen Regeln
      
        
        
          
      1. Schlüssel und Texte stehen in doppelten Anführungszeichen: "…"
        2. 
          
      2. Zwischen Schlüssel und Wert steht ein Doppelpunkt.
        3. 
          
      3. Einträge trennt ein Komma – nach dem letzten kommt keins.
        4. 
          
      4. true, false und null: klein und ohne Anführungszeichen.
        5. 
          
      5. Kommazahlen mit Punkt: 1.68 – nicht 1,68.
        6. 
          
      6. Keine Kommentare und keine einfachen Anführungszeichen '…'.
        7. 
        
      
      
      
      
      
        
      4 Typische Fehler
      
        
      
      
      
      
      Merksatz: Schlüssel in Anführungszeichen, Doppelpunkt, Wert – und zwischen den Einträgen ein Komma.
